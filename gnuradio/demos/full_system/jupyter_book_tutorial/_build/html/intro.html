Running Experiments and Capturing Data#

Welcome to the comprehensive tutorial on running experiments with the Bluesky-based experiment control framework!

What You’ll Learn#

This interactive tutorial will teach you:

✅ How to run experiments that capture data
✅ Multiple methods for experiment execution
✅ Understanding what data gets captured
✅ Verifying and retrieving captured data
✅ Analyzing and exporting results
✅ Troubleshooting common issues

This tutorial is organized into 8 chapters:

  1. Quick Start (5 Minutes) - Get data from your first experiment immediately

  2. Methods for Running Experiments - Learn four different approaches

Prerequisites#

Before starting this tutorial, ensure you have:

1. Environment Activation#

conda activate gnuradio

2. Required Packages#

The following packages should be installed:

  • bluesky - Experiment control framework

  • ophyd - Hardware abstraction layer

  • databroker - Data management and retrieval

  • matplotlib - Plotting

  • pandas - Data analysis

  • scipy - Scientific computing

Install them if needed:

pip install bluesky ophyd databroker matplotlib pandas scipy openpyxl h5py

3. Directory Location#

You should be in the full_system directory:

cd /Users/yak/Projects/EJFAT/ejfat_demos/gnuradio/demos/full_system

Verify Installation#

Let’s verify that all required packages are available:

# Verify imports
try:
    from bluesky import RunEngine
    from ophyd import Signal
    from databroker import Broker
    import matplotlib.pyplot as plt
    import pandas as pd
    import scipy
    
    print("✓ All required packages are available!")
    print("\nPackage versions:")
    print(f"  Bluesky: {__import__('bluesky').__version__}")
    print(f"  Ophyd: {__import__('ophyd').__version__}")
    print(f"  Pandas: {pd.__version__}")
    print(f"  Matplotlib: {matplotlib.__version__}")
    print("\nYou're ready to start!")
    
except ImportError as e:
    print(f"❌ Missing package: {e}")
    print("\nPlease install missing packages:")
    print("  pip install bluesky ophyd databroker matplotlib pandas scipy")

Check Working Directory#

Make sure you’re in the correct directory:

import os
from pathlib import Path

current_dir = Path.cwd()
print(f"Current directory: {current_dir}")

# Check if we're in the right place
expected_files = ['run_experiment.py', 'retrieve_data.py', 'config.py']
missing = [f for f in expected_files if not (current_dir / f).exists()]

if missing:
    print(f"\n⚠️  Missing expected files: {missing}")
    print("\nYou may need to change directory:")
    print("  import os")
    print("  os.chdir('/path/to/full_system')")
else:
    print("\n✓ You're in the correct directory!")
