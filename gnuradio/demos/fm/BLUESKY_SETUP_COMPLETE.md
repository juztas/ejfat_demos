## XML-RPC API Exposed

The GNU Radio flowgraph now exposes these methods via XML-RPC on port 8080:

- `get_freq()` - Returns current center frequency in Hz
- `set_freq(value)` - Sets center frequency to value (Hz)

These are automatically generated by the `zeromq_rpc_server` block based on the `freq` variable in the flowgraph.

## Technical Details

### ZeroMQ RPC Server Block

The `zeromq.rpc_server` block:
- Creates a ZeroMQ REP (reply) socket
- Binds to TCP port 8080
- Automatically exposes all flowgraph variables
- Naming convention: `get_<var>()` and `set_<var>(value)` methods
- Uses XML-RPC protocol over ZeroMQ transport

### Ophyd Device Architecture

```
┌───────────────────────┐
│ GNURadioFMTransmitter │
│   (Ophyd Device)      │
└───────────┬───────────┘
            │ has-a
            ▼
    ┌──────────────┐
    │ XMLRPCSignal │
    │  (frequency) │
    └──────┬───────┘
           │ uses
           ▼
    ┌─────────────┐      XML-RPC       ┌──────────────┐
    │ xmlrpc.     │ ◄─────────────────► │ GNU Radio    │
    │ ServerProxy │    tcp://...:8080   │ zeromq.rpc_  │
    └─────────────┘                     │ server       │
                                        └──────────────┘
```

### Signal Flow

1. Bluesky plan calls `fm_tx.frequency.set(98.5e6)`
2. `XMLRPCSignal.put()` is invoked
3. XML-RPC client calls `rpc.set_freq(98.5e6)`
4. GNU Radio `zeromq_rpc_server` receives request
5. Sets `self.freq` variable to 98.5e6
6. Variable callback updates `osmosdr_source` center frequency
7. SDR hardware retunes to new frequency
8. XML-RPC returns success
9. Signal reads back new value via `rpc.get_freq()`
10. Bluesky plan continues

## Troubleshooting

**If you get "zeromq not found":**
```bash
conda activate gnuradio
conda install -c conda-forge gnuradio-zeromq
```

**If port 8080 is in use:**
Edit both `.grc` and `.py` files to use a different port (e.g., 8081)

**If frequency doesn't change:**
- Check SDR is connected
- Verify flowgraph is running (not stopped/paused)
- Confirm frequency is in SDR's supported range
